## 1. Крестики-нолики

**Модуль:** «Основы программирования»  
**Репозиторий:** [github.com/IvanEvdokhin/tictactoe](https://github.com/IvanEvdokhin/tictactoe)  
**Сертификат:** [Основы программирования](certificates/Основы%20програмирования.pdf)

Браузерная игра для двух игроков на квадратном поле. Первый проект, где была реализована игровая логика на JavaScript.

**Стек:** HTML, CSS, JavaScript

**С чем работал:**
- двумерные массивы и состояние игрового поля;
- пошаговая логика хода и смена активного игрока;
- проверка победы по строкам, столбцам и диагоналям;
- разделение UI (`ui.js`) и логики (`logic.js`);
- поддержка поля произвольного размера через константу `BOARD_SIZE`.

## 2. NOEMI — адаптивный блог

**Модуль:** «Адаптивная и мобильная вёрстка»  
**Репозиторий:** [github.com/IvanEvdokhin/adaptive_and_mobile](https://github.com/IvanEvdokhin/adaptive_and_mobile)  
**Сертификат:** [Адаптивная и мобильная вёрстка](certificates/Адаптивная%20и%20мобильная%20верстка.pdf)

Одностраничный сайт блога о творчестве, спорте и образе жизни. Чистая вёрстка без фреймворков и препроцессоров.

**Стек:** HTML5, CSS3, JavaScript (Vanilla), SVG, Flexbox, Grid

**С чем работал:**
- семантическая разметка и методология **BEM**;
- CSS-переменные, Flexbox и Grid для раскладки;
- адаптивность на трёх брейкпоинтах: desktop (≥1200px), tablet (768–1199px), mobile (≤767px);
- адаптивные изображения (`<picture>`, разные фоны через `@media`);
- мобильное меню, модальное окно, `IntersectionObserver` для попапа;
- доступность: `aria-*`, `.visually-hidden`, плавная прокрутка к якорям.

## 3. Учёт личных финансов

**Модуль:** «Базовый JavaScript в браузере»  
**Репозиторий:** [github.com/IvanEvdokhin/financial_management](https://github.com/IvanEvdokhin/financial_management)  
**Сертификат:** [Основы JavaScript в браузере](certificates/Основы%20JavaScript%20в%20браузере.pdf)

Веб-приложение для учёта доходов и расходов. Готовая HTML/CSS-разметка и сервер уже были в проекте — задача заключалась в реализации клиентской JavaScript-логики.

**Стек:** JavaScript, XMLHttpRequest, Node.js, Express, AdminLTE

**С чем работал:**
- AJAX-запросы через `XMLHttpRequest` и универсальная функция `createRequest`;
- разделение на API-слой (`public/js/api/`) и UI-слой (`public/js/ui/`);
- CRUD-операции: счета, транзакции, регистрация, авторизация, выход;
- наследование классов (`Entity`, `AsyncForm`), виджеты, модальные окна, формы;
- управление состоянием приложения через `App.js` (`init` / `user-logged`);
- работа с `localStorage` для хранения данных пользователя.

## 4. Биржа Неткоинов

**Модуль:** «Основы JavaScript»  
**Репозиторий:** [github.com/IvanEvdokhin/netcoin](https://github.com/IvanEvdokhin/netcoin)  
**Сертификат:** [Основы JavaScript](certificates/Основы%20JavaScript.pdf)

Сайт-биржа крипто-стартапа: покупка внутренней валюты **Неткоин**, конвертация, переводы другим пользователям и список избранных.

**Стек:** JavaScript, Node.js, Express, REST API

**С чем работал:**
- связка готового DOM-слоя с серверным API;
- авторизация и регистрация (`UserForm`, `ApiConnector`);
- личный кабинет: профиль, баланс, курсы валют с ЦБ РФ;
- операции с деньгами: пополнение, конвертация, перевод (`MoneyManager`);
- избранные пользователи: добавление, удаление, обновление UI (`FavoritesWidget`);
- асинхронные колбеки, обработка ошибок сервера, периодическое обновление данных.

## 5. Retro Game

**Модуль:** «Продвинутый JavaScript»  
**Репозиторий:** [github.com/IvanEvdokhin/retro_game](https://github.com/IvanEvdokhin/retro_game)  
**Сертификат:** [Продвинутый JavaScript и основы React](certificates/Продвинутый%20JavaScript%20и%20основы%20React.pdf)

Пошаговая фэнтези-игра на поле 8×8: герои против нечисти, бесконечные уровни, сохранение и загрузка прогресса.

**Стек:** JavaScript (ES6+), Webpack 5, Babel, ESLint, Jest, localStorage

**С чем работал:**
- настройка окружения: Webpack Dev Server, Babel, production-сборка;
- ООП: базовый класс `Character`, наследование типов персонажей, запрет `new Character()`;
- игровая логика: ход, атака, зоны перемещения и атаки, ИИ противника;
- сериализация состояния (`GameState`, `GameStateService`) и сохранение в `localStorage`;
- разделение ответственности: `GamePlay` (UI), `GameController` (логика), `GameState` (данные);
- автотесты Jest — 48 тестов на утилиты, персонажей, генераторы, ИИ;
- дополнительно: бесконечный цикл уровней, toast-уведомления, улучшенный ИИ с весами.

## 6. ИдёмВКино — онлайн-бронирование билетов

**Курс:** «Веб-разработчик с нуля: Backend-разработка на PHP»  
**Репозиторий:** [github.com/IvanEvdokhin/online_cinema](https://github.com/IvanEvdokhin/online_cinema)  
**Сертификат:** [Свидетельство о заверении обучения](certificates/Свидетельство%20о%20заверении%20обучения.pdf)

Дипломная работа всего курса.
Полноценная система бронирования билетов в кинотеатр: публичный сайт для гостей и административная панель для управления залами, сеансами и продажами.

**Стек:** PHP 8.2+, Laravel 13, SQLite, Laravel Sanctum, React 18, Vite, React Router

**С чем работал:**
- REST API на Laravel: расписание, бронирование, QR-билеты;
- аутентификация администратора через Sanctum (Bearer token);
- CRUD для залов, фильмов, сеансов; настройка схемы зала и цен;
- React SPA: выбор сеанса, мест, оплата, электронный билет с QR-кодом;
- админ-панель: активация залов, открытие/приостановка продаж;
- валидация через Form Request, хеширование паролей (`Hash::make`);
- миграции, сиды, SQLite, загрузка постеров, CORS между frontend и backend.
