## Коммерческий проект: Бегура — интернет-магазин и сайт производителя спортивной обуви

**Тип:** коммерческий проект (вёрстка по макету и интеграция в CMS)  
**Сайт:** [begura.codeprode.ru](http://begura.codeprode.ru/) (тестовый домен, после переноса будет основной)  
**Код:** в закрытом репозитории

Сайт российского производителя обуви для единоборств, танцев и гимнастики: каталог с размерами, корзина, оформление заказа, раздел «Разработка обуви на заказ», доставка, контакты и FAQ. Работал над проектом в команде: сверстал сайт по макету Figma, внёс правки, которых не было в макете, и посадил вёрстку на 1С-Битрикс. Наполнением каталога занимались другие участники.

**Стек:** 1С-Битрикс (инфоблоки, каталог, торговые предложения, интернет-магазин), PHP (шаблоны и компоненты Битрикса), MySQL, HTML5, CSS3 (BEM, CSS variables), JavaScript (Vanilla), Fancybox, Figma, Git

**Моя роль:** фронтенд и интеграция вёрстки в 1С-Битрикс

**С чем работал:**

- вёрстка страниц по макету Figma: главная, каталог, карточка товара, корзина, доставка, контакты, FAQ;
- внесение правок по ходу проекта, в том числе вне исходного макета;
- адаптивная вёрстка и мобильное меню;
- кастомный шаблон сайта на Битриксе (`eshop_bootstrap_v4`): перенос статической вёрстки в шаблоны и компоненты CMS;
- главная страница на инфоблоках: герой, о компании, маркетплейсы, кастомный пошив, отзывы;
- базовая вёрстка каталога под данные из инфоблоков;
- клиентские фильтры каталога на Vanilla JS: категория, размер, цена, сортировка, поиск;
- товары с размерами (торговые предложения): выбор размера и добавление предложения в корзину;
- ajax-корзина: добавление, изменение количества, удаление, выбор позиций;
- формы «Обсудить проект», «Купить в 1 клик», «Запросить прайс-лист»;
- импорт каталога из Excel с фотографиями;
- галерея товара на Fancybox, виджет Яндекс.Карт на странице контактов;
- юридические страницы: оферта, политика конфиденциальности, лицензия;
- тестовый контур: закрытый доступ, `noindex`, закрытый `robots.txt`.

**Что не входило в мою работу:** интеграция с CDEK и калькулятор доставки, платёжные системы, наполнение каталога.
